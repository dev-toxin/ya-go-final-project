# Планировщик задач

Веб-приложение TODO-листа на Go. Сервер раздаёт готовый фронтенд и предоставляет REST API для задач: создание, просмотр, поиск, редактирование, выполнение и удаление.

## Возможности

- создание, получение, редактирование и удаление задач;
- отметка о выполнении: одноразовая задача удаляется, повторяющаяся переносится на следующую дату;
- сортированный список ближайших задач;
- поиск по заголовку, комментарию или дате;
- правила повторения: ежедневно/через N дней (`d N`), ежегодно (`y`), по дням недели (`w`) и дням месяца (`m`);
- опциональная JWT-аутентификация.

## Настройки

| Переменная | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `TODO_PORT` | TCP-порт сервера | `7540` |
| `TODO_DBFILE` | путь к SQLite-файлу | `scheduler.db` |
| `TODO_PASSWORD` | пароль для включения JWT-аутентификации | не задан |

Если `TODO_PASSWORD` пуст, API доступно без аутентификации. Если пароль задан, сначала выполните `POST /api/signin` с JSON `{"password":"<пароль>"}`, затем передавайте полученный токен во все защищённые запросы в заголовке `Authorization: Bearer <token>`.

## Локальный запуск

Требуется Go 1.24 или новее.

```bash
go run main.go
```

Откройте [http://localhost:7540](http://localhost:7540). При первом запуске будет создана SQLite-база `scheduler.db`.

Пример запуска с аутентификацией:

```bash
TODO_PASSWORD=secret go run main.go
```

## Docker

Сборка образа:

```bash
docker build -t scheduler .
```

Запуск с постоянным хранением БД в текущей директории:

```bash
docker run --rm -p 7540:7540 \
  -v "$(pwd)/scheduler.db:/app/scheduler.db" \
  -e TODO_PASSWORD=secret \
  scheduler
```

## Тесты

Сначала запустите сервер в отдельном терминале, затем выполните:

```bash
go test ./tests
```

Для проверки расширенных правил повторения и поиска в `tests/settings.go` установите `FullNextDate = true` и `Search = true`.

## Структура

```text
pkg/api     HTTP-обработчики и вычисление повторений
pkg/db      SQLite-схема и доступ к задачам
pkg/server  запуск HTTP-сервера
web         статический фронтенд
tests       тесты задания
```
